# guardedverse

Source for <https://selcukorkmaz.github.io/guardedverse/>, the hub site for
three R packages for leakage-aware evaluation:

| Package | Job | Site |
|---|---|---|
| [splitGraph](https://github.com/selcukorkmaz/splitGraph) | Dataset structure as a typed dependency graph | <https://selcukorkmaz.github.io/splitGraph/> |
| [bioLeak](https://github.com/selcukorkmaz/bioLeak) | Leakage-safe folds, guarded preprocessing, auditing | <https://selcukorkmaz.github.io/bioLeak/> |
| [fastml](https://github.com/selcukorkmaz/fastml) | Guarded model training and comparison | <https://selcukorkmaz.github.io/fastml/> |

## Repository layout

The shared pkgdown theme sits inside this directory for convenience but is a
**separate repository** (`selcukorkmaz/leakdown`), and is gitignored here:

```
GitHub/guardedverse/      <- this repo -> selcukorkmaz.github.io/guardedverse/
    _quarto.yml, *.qmd, styles.scss, .github/
    leakdown/             <- separate repo, pushed as selcukorkmaz/leakdown
```

Push `leakdown` **before** the three package repositories: their pkgdown
workflows install it via `Config/Needs/website: selcukorkmaz/leakdown`, and that
step fails if the repository does not exist yet.

Package documentation is not here: it is generated by pkgdown from each
package's own repository.

## Building locally

```bash
quarto preview
```

Nothing is executed at render time — the worked example on **Get started** is
shown rather than run, so the site does not need the modelling dependency stack
installed. If executable chunks are ever added, add an R setup step to
`.github/workflows/publish.yml`.

## Deployment

`.github/workflows/publish.yml` renders on every push to `main` and deploys via
the GitHub Pages artifact (not a `gh-pages` branch).

`actions/configure-pages` runs with `enablement: true`, so the workflow turns
Pages on by itself. No manual **Settings -> Pages** change is required; if the
setting is ever flipped back to *Deploy from a branch*, the next run resets it
to *GitHub Actions*.

## Visual consistency with the package sites

The palette and fonts here are deliberately the same as the three pkgdown sites,
which get them from the shared
[leakdown](https://github.com/selcukorkmaz/leakdown) template package. Two
copies of the palette exist — `styles.scss` here, and `leakdown`'s
`inst/pkgdown/BS5/extra.scss` — because Quarto and pkgdown cannot share a
stylesheet. If you change an accent colour, change it in both.

| Package | Accent (light) | Accent (dark) |
|---|---|---|
| splitGraph | `#4C78A8` | `#7BA7D4` |
| bioLeak | `#2A7F62` | `#5FB99A` |
| fastml | `#B85C2E` | `#E08A58` |
